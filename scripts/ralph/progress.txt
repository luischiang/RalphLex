## Codebase Patterns
- Python venv at `.venv/`, installed via `pip install -e ".[dev]"` from `pyproject.toml` (deps: fastapi, uvicorn, pydantic, pydantic-settings, anthropic, httpx, aiosqlite; dev deps: pytest, pytest-asyncio, ruff).
- FastAPI app lives at `backend/main.py` (`app` object), all routes mounted under `/api/...`. Run: `.venv/bin/uvicorn backend.main:app --reload --port 8000`.
- Tests live in `tests/` (pytest config in `pyproject.toml`: `testpaths = ["tests"]`, `asyncio_mode = "auto"`). Use `fastapi.testclient.TestClient` for API tests.
- Lint backend with `ruff check backend tests`.
- Frontend is Vite + React + TS + Tailwind v4 in `frontend/`. Tailwind v4 uses the `@tailwindcss/vite` plugin — no `tailwind.config.js`/`postcss.config.js` needed, just `@import "tailwindcss";` in `src/index.css` and `tailwindcss()` in `vite.config.ts` plugins array.
- `vite.config.ts` proxies `/api/*` to `http://localhost:8000` and dev server is pinned to port 3000.
- Frontend lint is `npm run lint` (oxlint), build is `npm run build` (`tsc -b && vite build`).
- Makefile targets: `install`, `dev-backend`, `dev-frontend`, `dev` (both via `make -j2`), `test`, `lint`.
- Case working directories will live under `data/cases/{case_id}/` (gitignored except `.gitkeep`).
- **Sandbox gotcha:** background dev servers started with shell `&`/`nohup` in the Bash tool get killed/disconnected unpredictably (cwd doesn't carry into `&`-backgrounded subshells the way you'd expect either). Use the Bash tool's native `run_in_background: true` param to launch uvicorn/vite dev servers instead, and stop them with `TaskStop`.
