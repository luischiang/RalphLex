## Codebase Patterns
- Python venv at `.venv/` — use `.venv/bin/` prefix for all Python tools (pytest, ruff, mypy, uvicorn)
- LegalStore uses sync sqlite3 (not aiosqlite) — simpler and sufficient for this use case
- For httpx async client mocking: use `MagicMock` for response (json/raise_for_status are sync), `AsyncMock` for client.get and context manager methods
- `_make_httpx_mock()` helper in test_legal_db.py creates properly wired httpx.AsyncClient mock
- `pyproject.toml` uses setuptools with explicit package find: `include = ["backend*", "tests*"]`
- Backend runs on port 8000, frontend on port 3000 with Vite proxy for `/api` to backend
- Tailwind CSS v4 via `@tailwindcss/vite` plugin — use `@import "tailwindcss"` in index.css
- Ruff for linting/formatting, mypy for typechecking, pytest with asyncio mode auto
- Frontend uses Vite 6+ template — no separate tailwind.config.js needed with v4
- Use `datetime.now(UTC)` instead of `datetime.utcnow()` — the latter is deprecated in Python 3.12+
- Models are in `backend/models/case.py`, re-exported from `backend/models/__init__.py`
- CaseFolderManager in `backend/services/case_folder.py` — use `tmp_path` fixture in tests for isolation
- mypy `warn_return_any` is on — annotate return types from `json.loads()` explicitly (e.g., `dict[str, object]`)
- API routers registered in `backend/app.py` with `prefix="/api"` — add new routers there
- Use `unittest.mock.patch` on module-level `folder_manager` to inject tmp_path-based CaseFolderManager in tests
- FastAPI TestClient (sync) is sufficient for testing — no need for httpx AsyncClient
- `backend/config.py` uses pydantic-settings `Settings` class — import `settings` singleton for env vars
- LLMAgent in `backend/agents/base.py` — pass `client=mock_client` in tests to inject mocked Anthropic client
- Use `asyncio.to_thread(lambda: client.messages.create(...))` to wrap sync Anthropic SDK for async
- mypy needs `cast(list[MessageParam], messages)` for Anthropic SDK message types
- Anthropic SDK content blocks are union types — use `hasattr(block, "text")` guard + `type: ignore[union-attr]`
- ClaimantAgent/RespondentAgent extend LLMAgent — use `generate_argument()` with case_facts, iteration, opponent_argument
- Convergence detection via `difflib.SequenceMatcher` — threshold 0.85 by default, weighted across argument fields
- ArgumentLoop orchestrator alternates claimant/respondent — persists each round to iterations/round_{n}_{role}.json
- For tests needing multiple sequential LLM responses, use `client.messages.create.side_effect = [resp1, resp2, ...]`
